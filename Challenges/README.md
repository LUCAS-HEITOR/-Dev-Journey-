## 📌 Overview

This section is dedicated to tracking daily problem-solving practices across competitive programming and interview preparation platforms.

Every challenge is approached with a focus on:
- **Optimal Time & Space Complexity ($O(n)$, $O(\log n)$, $O(1)$)**;
- **Pattern Recognition** (Sliding Window, Two Pointers, Fast & Slow Pointers, Monotonic Stack, Dynamic Programming);
- **Clean Code & Edge Case Handling**.
